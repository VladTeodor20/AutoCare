
# AI Log – Stage 4

## Project
AutoCare – Car Maintenance Manager

## AI Tool Used
ChatGPT (OpenAI)

## Objective
Implement reusable React components to display maintenance tasks dynamically from data.

## AI Assistance

ChatGPT was used to:
- Analyze the existing React application.
- Create the MaintenanceCard component.
- Create the MaintenanceList component.
- Pass data between components using props.
- Render maintenance tasks using map() and unique keys.
- Implement conditional rendering for an empty list.
- Connect the new components to App.jsx.
- Assist with testing and documentation.

## Implementation
Two React components were created:

1. MaintenanceCard.jsx – displays a single maintenance task.
2. MaintenanceList.jsx – generates a list of task cards from the array.

The temporary JSON display was replaced with reusable React components.

## Testing
The following tests were performed:
- Displaying three maintenance tasks.
- Checking the browser console for React warnings.
- Testing the empty list message.
- Changing a task's completed status.
- Restoring the original test data.

The tests completed successfully.

## Conclusion
AI assistance helped implement and understand reusable React components, props, list rendering, and conditional rendering.
